01 · Limits

Every plan window, one glance up.

Collapsed, the notch shows a ring and a number for the account closest to trouble. Hover and it opens into session and weekly meters, reset times and the session you are in right now. Scroll to page through accounts.

  • Every agent home is its own account: ~/.claude, ~/.claude_multi/*, ~/.codex*, Cursor
  • Found automatically on first launch

02 · Pace

Not just how much. How fast.

81% used sounds bad on a Thursday and fine on a Sunday. The white tick on each meter is where you would be at an even pace. Run ahead of it and the color moves from green to amber to red, with a forecast of when you run out.

  • On track within 5 points of the clock
  • Ahead of pace up to 12 points over
  • Runs out 7:24 PM when the trend beats the reset

03 · Alerts

It taps you on the shoulder. Then gets out of the way.

At 75%, 90% and 100% of a window, an alert drops out of the notch with the projected run-out time. Another one says when a window resets. No dock icon, no menu bar clutter, optional sound. Full-screen apps keep the notch hidden.

  • Quiet hours on a schedule, or snooze from the notch
  • Follows a macOS Focus with one Shortcuts automation and agentilo quiet
  • Approvals and limit-reached alerts can still come through

04 · Agents

All your agents, one pulse.

Running Claude Code and Codex sessions, what each is doing, and which one is waiting for you. A dot on the pill pulses when one needs input; while one works, the pill spins with the turn time. When it finishes, the alert shows the start of its reply, so you know whether to look. Click a row to jump to its pane.

  • Reads herdr and/or Claude Code and Codex hooks
  • Hooks are marked and reversible; your other hooks stay untouched

05 · Approvals

Say yes without switching windows.

Opt in and Claude Code permission prompts show up in the notch with the full command and Allow, Deny or Always. Leave one unanswered and it goes back to the terminal after a timeout, as does any prompt for the pane you are already looking at.

06 · Activity

Half a year of work, in one glance.

A 26-week heatmap and streak, today's prompts, tool calls and sessions, top projects, and what it all would cost at API list prices. Daily totals are kept on disk, so history outlives the agents' own 30-day log cleanup.

For scripts

Pipe it anywhere.

A loopback-only API and a tiny CLI, so your status line, tmux bar or shell prompt can read the same numbers. Falls back to cached values when the app is closed.

Private by design

Your tokens stay home.

01

Read-only credentials

Uses the sign-ins Claude Code, Codex and Cursor already store. Never refreshes or rewrites them, and sends each only to its own provider.

02

No telemetry

No account, no analytics. The only requests are the three usage endpoints, through your proxy if you set one, and a daily update check.

03

Loopback only

The local API listens on 127.0.0.1, refuses browser pages, and needs a per-install token for anything that changes state.

04

Works offline

Offline or rate limited? Codex limits come from its own logs; Claude limits are estimated from tokens logged since the last check.
